# Bridge 安全与隐私

- Bridge 直接读取本机仓库登记表，只扫描登记表内的仓库，不访问未登记目录。
- 扫描跳过隐藏目录、`.obsidian`、`.git`、`.trash`、`node_modules`、符号链接与构建目录，
  只读取 Markdown 文件。
- 索引只保存路径、标题、别名、标签、修改时间和大小，不保存正文；正文在打开预览时按需
  实时读取。
- 读取正文前校验目标位于登记仓库根目录内，拒绝绝对路径、根路径、`..` 逃逸与符号链接越界。
- Bridge 不执行笔记内容，不访问远程服务。
- 安装只写 Bridge 自己的插件目录，并在 `community-plugins.json` 中登记 Bridge 自身条目；
  不关闭受限模式、不修改其他插件。
- 旧版 HTTP 服务仅保留兼容，只绑定 `127.0.0.1`；访问令牌随机生成，保存在 AppData 的独立
  `bridge-service.json` 中，不写入日志或 UI。

当前 JSON frontmatter 读取器只支持单行列表形式；复杂 YAML 会安全地退化为空别名或标签。
