# Bridge 安全与隐私

- HTTP 服务只绑定 `127.0.0.1`，不向局域网监听。
- 访问令牌随机生成，保存在 AppData 的独立 `bridge-service.json` 中，不写入日志或 UI。
- Hub 只扫描用户已登记仓库中的 Markdown 文件，跳过隐藏目录、`.obsidian`、`.git`、
  `.trash`、`node_modules`、符号链接与构建目录。
- 索引只保存路径、标题、别名、标签、修改时间和大小，不保存正文。
- 打开请求必须命中索引中的仓库和笔记，并拒绝绝对路径、根路径和 `..` 路径逃逸。
- Bridge 不执行笔记内容，不访问远程服务，也不扫描其他仓库。
- 自动安装只写 Bridge 自己的插件目录，并且需要用户授权。

当前 JSON frontmatter 读取器只支持单行列表形式；复杂 YAML 会安全地退化为空别名或标签。
