# Obsidian Hub 2.1.0-preview.1

- 新增本地工作流活动日志，记录创建认知/输出、任务更新和 Echo 已阅操作的成功或失败，不保存笔记正文。
- 工作台提供活动查看、损坏记录警告、刷新和二次确认清空；清空活动不会改变笔记、任务或工作流状态。
- 业务写入成功但日志不可用时保持业务成功并给出非阻断提示，避免用户重试造成重复创建。
- 新笔记已经创建但 Obsidian 打开失败时提供“重新打开”，重试不会再次创建文件。
- 预览更新通道版本校验扩展到 2.x，继续保持独立安装身份、AppData、签名与正式更新源隔离。

已安装 2.0 预览版更新通道的用户可在 Hub 主页使用“检查更新”直接升级。preview.0 仍需手动安装新版才能切换到预览更新通道。预览功能建议先在临时仓库验证并备份重要数据。
