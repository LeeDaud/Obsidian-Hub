# Obsidian Hub 2.0.0-preview.1

- 集中单页工作台，恢复暖灰与陶土色的纯粹风格，统一悬停背景圆角。
- Echo 在 Main 创建认知笔记，Main 与可选 Knowledge 来源在 Output 创建输出笔记；仅创建标题、属性、跨库链接与空正文，正文由用户完成。
- 2.0 使用独立安装身份、AppData 和预览更新通道，不改变 1.0 配置或正式更新源。
- 更新仅由用户触发，下载后验证签名，不做后台静默更新。

preview.0 必须手动安装一次本版本以切换预览更新通道；本版本之后可使用 Hub 更新入口。预览功能建议先在临时仓库验证并备份重要数据。
