# Obsidian Hub 2.1.0

- 工作台自动感知已登记仓库的 Markdown 新增、修改、删除及目录改名，局部更新笔记、任务和关系；任务写入与全量刷新期间缓冲变化，过期读取不覆盖新状态。
- 正在阅读的预览保留正文，文件变化后提示手动刷新；监听异常、读取失败、网络仓库和事件过多会明确提示手动刷新，离开工作台或退出时释放监听。
- Echo 成功预览后可跳过 Main 直接创建 Output，支持可选 Knowledge 资料；仍按已配置目录生成标题、来源和空正文，来源不改写，同名不覆盖。
- 支持多篇 Echo 汇入一篇 Main/Output、多篇 Knowledge 关联一篇 Output；关联模式可一次选择最多 50 条并统一原子确认，任何一条失效都会阻断整批。
- 自动识别正文 Bridge 跨库链接，排除 frontmatter、代码、引用块代码围栏及注释；稳定仓库 ID 优先，旧名称歧义明确提示，不按标题猜测。
- 看板显示实际仓库名，支持直接关系、展开上下游和仅相关笔记；来源、下游、资料和正文链接分组计数，区分来源字段、手动与正文证据。Echo 直达连线绕开 Main，相关卡片高度自适应，窄窗口保留 2×2。
- 自动候选不持久化，删除正文链接后自动关系随局部刷新消失；配置与手动关系沿用原 schema，正式身份、AppData、签名密钥和更新源保持一致。

正式 2.0.0 用户可从主页“检查更新”下载并安装。配套 Bridge 为 0.7.0，通过仓库管理显式部署，插件继续独立只读运行。自动化与模拟浏览器检查已完成，真实安装升级及网络盘行为仍需实机验收。
