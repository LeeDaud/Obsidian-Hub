# Obsidian Hub 2.0.0-preview.2

- 默认首页改为仓库管理，顶部导航依次为仓库管理、工作台。
- 工作台直接展示全部任务，按来源笔记最近修改时间排序，并修复长任务与小窗口错位。
- Echo 灵感先在 Hub 内只读预览，成功读取后再标记已阅或创建认知笔记；任务也可直接预览来源笔记。
- 修复从 Hub 打开笔记时 Obsidian 偶发显示“Vault not found”的扩展路径兼容问题。
- 保持 Echo → Main → Output 跨仓库创建流程、独立 2.0 安装身份和签名预览更新通道。

已安装 preview.1 的用户可在 Hub 主页使用“检查更新”直接升级。preview.0 仍需手动安装 preview.2 才能切换到预览更新通道。预览功能建议先在临时仓库验证并备份重要数据。
