# Obsidian Hub 2.0.0

- 正式发布多仓库知识工作台，默认显示全部任务，支持标题、路径、别名与标签搜索。
- 支持 Echo → Main → Output 直接创建流程，可选 Knowledge 资料；新笔记只含标题、来源属性、跨库链接与空正文，来源不被改写。
- 提供四库流程看板、来源追溯与资料关系，卡片选择、原位确认、临时连线和列内搜索；同名笔记不会自动关联。
- Markdown 正文安全只读预览，任务勾选行内更新并在失败时回滚；活动日志只记录动作元数据。
- 隐藏流程看板外层滚动条，与仓库管理页一致，保留外层滚动及四列内部滚动条。
- 沿用正式安装身份、配置目录和签名更新通道，读取旧正式登记表并使用既有 schemaVersion 1 → 2 迁移。

正式 0.4.0 用户可从主页“检查更新”下载并安装。预览用户需手动安装正式版，并从正式 Hub 重新部署 Bridge；预览配置、手动关系与活动日志不自动覆盖正式数据。首次使用需设置角色与默认目录。实际安装、应用内跨版本升级和真实仓库流程仍需实机验收。
