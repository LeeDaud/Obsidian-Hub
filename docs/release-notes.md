# Obsidian Hub 2.1.0-preview.2

- 工作台新增四库流程看板，按 Echo、Main、Output、Knowledge 展示最近笔记，保留全部任务默认视图。
- 选中笔记可追溯来源、下游与资料关系，支持关系高亮、连线和定位；窄窗口使用 2×2 布局，各列独立滚动。
- 支持确认后关联已有笔记，关系仅保存在 Hub 自身 AppData，不改写已有笔记正文；可解除手动关联。
- 自动关系只来自 Hub 生成的 origin/references，相似标题不自动关联；移动、重命名或仓库离线显示断链提示。
- 看板复用安全预览、直接创建 Main/Output 和 Obsidian 打开；Echo 创建认知仍需先成功预览。
- 延续活动日志、创建后打开失败的恢复、任务行内更新，以及独立安装身份和预览更新通道。

已安装预览更新通道的用户可在 Hub 主页点击“检查更新”升级。preview.0 仍需手动安装新版才能迁移通道。真实仓库与 Obsidian 跳转仍需实机验收。
