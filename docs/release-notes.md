# Obsidian Hub 2.1.0-preview.3

- 四库流程看板支持直接在卡片上选择关联笔记，通过顶部原位确认保存关系。
- 支持从 Echo、Main、Output、Knowledge 发起合法方向的关联，候选选择与预览保持浏览状态。
- 新增待确认关系的临时高亮与连线、候选预览、取消和列内搜索；优化列内滚动条及窄窗口体验。
- 加强重复关联、并发保存、关系加载失败和刷新后文件变化的处理，保留键盘取消与错误恢复。
- 手动关系仍只保存在 Hub 预览版 AppData，不改写已有笔记；沿用独立安装身份与预览更新通道。

已安装预览更新通道的用户可在 Hub 主页点击“检查更新”升级。preview.0 仍需手动安装新版才能迁移通道。真实仓库与 Obsidian 跳转、实际安装升级仍需实机验收。
