# Obsidian Hub 2.0.0-preview.3

- 待办任务改为行内静默更新，不再因单次勾选刷新整个工作台；写入失败会恢复原状态并提示原因。
- 同一来源笔记的任务在写入期间统一防止并发，并同步最新内容摘要，避免后续操作误报冲突。
- 重做 Hub 内 Markdown 预览，支持属性、嵌套列表、任务、表格、连续引用、代码块和常用行内格式。
- 扩大预览空间，长正文只在正文区滚动，页头、文件信息和操作按钮保持可见；长路径、表格和代码不再撑破布局。
- 原始 HTML 继续作为纯文本显示，外部链接仅接受 HTTP/HTTPS，保持跨库链接预览能力。

已安装 preview.1 或 preview.2 的用户可在 Hub 主页使用“检查更新”直接升级。preview.0 仍需手动安装新版才能切换到预览更新通道。预览功能建议先在临时仓库验证并备份重要数据。
